## Instrucciones
- Instala las dependencias
```  
pip install -r requirements.txt
```
- Instala graphviz en el siguiente enlace
[Link descarga](https://graphviz.org/download/)

- Agregar la ruta a las variables de entorno del sistema 
- Verificar si esta instalado con el comando:
```  
dot -V
```
- Dirigete a la carpeta Proyecto4
```  
cd Proyecto4
```
- Ejecuta el comando para ejecutar el codigo
```  
streamlit run main.py
```
